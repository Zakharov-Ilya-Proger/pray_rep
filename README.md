# Сервис обработки очереди Redis

## 1. Настройка и установка Docker

Для установки и запуска системы docker а сервер перейдите по [ссылке](https://docs.docker.com/engine/install/) и настройте.

## 2. Скачайте модель

Для перевода аудио в текст, нужно скачать Vosk модель с сайта по [ссылке](https://alphacephei.com/vosk/models)

Запомните путь до корневой директории модели
```
/home/usr_nm/vosk_model_dir
```

## 3. Настройка .env

В (переменные окружения/прописать в docker-compose.yml) нужно внести следующие поля:

- WORKERS=${WORKERS} (Количество процессов для обработки аудио)
- QUEUE_KEY=${QUEUE_KEY} (Название очереди оз которой брать )
- REDIS_URL=${REDIS_URL} (ссылка доступа на )
- MODEL_PATH=${MODEL_PATH} (путь до модели Vosk из прошлого шага)
- API_RECORD_PASS=${API_RECORD_PASS} (Пароль от медиасервер)
- API_RECORD_URL=${API_RECORD_URL} (URL по которому доступен медиасервер)

## 4. Сборка и запуск приложения

Убедитесь, что сервис Redis уже работает.

Если сервис уже поднят и работает

Перейдите в корневую директорию, где находится приложение

```bash
sudo docker compose up -d
```
Данная команда выполнит сборку контейнера и подключит его в общую сеть контейнеров
